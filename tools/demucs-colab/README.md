# ញែកភ្លេងដោយ Demucs លើ **Google Colab (GPU)** → គេហទំព័រ

គេហទំព័រ (backend នៅ cloud) ត្រូវការម៉ាស៊ីនញែកភ្លេងដើម្បីញែក **សំឡេងនិយាយ** ចេញពី
**ភ្លេង/សំឡេងផ្ទៃខាងក្រោយ** មុនពេលបញ្ចូលសំឡេងខ្មែរ។ ថតនេះបង្ហាញរបៀបរត់ម៉ាស៊ីននោះលើ
**Google Colab** ជំនួស Termux លើទូរស័ព្ទ — **លឿនជាងច្រើនដង** ព្រោះ Colab ផ្តល់ GPU ឥតគិតថ្លៃ។

> **ហេតុអ្វីលឿនជាង?** ការញែកភ្លេងជាការគណនាធ្ងន់។ លើ CPU របស់ទូរស័ព្ទ វាចំណាយ ~១០–៣០ ដង
> នៃប្រវែងសំឡេង (សំឡេង ១ នាទី ≈ ១០–៣០ នាទី)។ លើ GPU របស់ Colab វាត្រឹមប៉ុន្មានវិនាទី។
> ដូច្នេះគេហទំព័រក៏ត្រូវបានកែឲ្យផ្ញើអូឌីយ៉ូ **វែងជាងមុនក្នុង ១ request** ពេលវាដឹងថា
> ម៉ាស៊ីននោះមាន GPU (មើលជំហានទី ៤)។

## ជំហាន ១ — បើក notebook

បើកឯកសារ `tools/demucs-colab/demucs_colab.ipynb` ក្នុង [Google Colab](https://colab.research.google.com/)
(`File → Upload notebook` បើអ្នកទាញវាចេញពី repo នេះ) រួចកំណត់៖

```
Runtime → Change runtime type → T4 GPU → Save
```

⭐ **មិនចង់ប្រើ notebook?** ក្នុង Colab បើក cell ថ្មី រួច paste បន្ទាត់តែមួយនេះ៖

```
!curl -fsSL https://raw.githubusercontent.com/kitreaksa78-debug/Sal/main/tools/demucs-colab/colab-start.sh | sh
```

វាធ្វើអ្វីៗទាំងអស់៖ ដំឡើង Demucs → បើក API (ដោយប្រើ GPU) → បើក Cloudflare Tunnel →
ពិនិត្យដោយខ្លួនឯងថា URL នោះដើរពិតពីខាងក្រៅ → រួចបង្ហាញ **URL** និង **API Key**។

វាចំណាយពេល ១–៣ នាទីក្នុងការដំឡើង (តែម្ដងក្នុងមួយ session)។

## ជំហាន ២ — យក URL និង API Key

នៅចុងបញ្ចប់ អ្នកនឹងឃើញ៖

```
✅ ✅ ✅  DEMUCS លើ COLAB ដំណើរការហើយ!

    URL      : https://xxxx-xxxx.trycloudflare.com
    API Key  : <key>
```

បើអ្នកកំណត់ `DEMUCS_API_KEY` ក្នុង cell (ដូចនៅក្នុង notebook) key នោះជារបស់អ្នកដដែល
រាល់ពេល — ដូច្នេះពេលបើក session ថ្មី អ្នកគ្រាន់តែប្តូរ **URL** តែមួយ។ បើមិនកំណត់ វា
បង្កើត key ថ្មីឲ្យ (រួចបង្ហាញវា)។

## ជំហាន ៣ — មកផ្ទៀងផ្ទាត់ខ្លួនឯង

បើក URL នោះក្នុង browser (បន្ថែម `/`): គួរឃើញ

```json
{"status":"ok","service":"Demucs API","version":"1.2","model":"htdemucs","device":"cuda","busy":false}
```

* `device: cuda` = **កំពុងប្រើ GPU** ✅ (បើឃើញ `cpu` នោះ runtime គ្មាន GPU)
* `version: 1.2` = ជំនាន់ដែលប្រើ GPU បាន

## ជំហាន ៤ — ប្រាប់គេហទំព័រ (រកមិនឃើញបញ្ហា ១ នាទី)

អ្នក **មិនត្រូវការអ្នកអភិវឌ្ឍ** ទេ ហើយមិនត្រូវ push ឬ deploy អ្វី៖

1. ចូលគេហទំព័រដោយគណនី **Admin**។
2. ផ្ទាំង **ស្ទូឌីយោ** → កាត **«ញែកភ្លេង · Demucs API»**។
3. paste **URL** ក្នុងវាល URL និង **API Key** ក្នុងវាល API Key។
4. ចុច **«រក្សាទុក និងសាកល្បង»**។ ពេលជោគជ័យ វាបង្ហាញឈ្មោះ service៖
   `Demucs API v1.2 · htdemucs · cuda` → **`cuda` គឺជាភស្តុតាងថា GPU កំពុងធ្វើការ**។
5. បកប្រែវីដេអូសាកល្បង ១–២ នាទី។ ក្នុង log អ្នកនឹងឃើញ pieces នៃ ~៩០ វិនាទី
   (មិនមែន ១៥ វិនាទីដូចលើទូរស័ព្ទទេ) — នោះជាសញ្ញាថាគេហទំព័រដឹងថាមាន GPU។

> ការផ្លាស់ URL មិនត្រូវការ redeploy ទេ — URL ដែលរក្សាទុកក្នុងកាតឈ្នះតម្លៃក្នុង server។
> ដូច្នេះពេល Colab ដាច់ រួចបើកឡើងវិញ គ្រាន់តែ paste URL ថ្មីក្នុងកាត។

## អ្វីដែលអ្នកត្រូវដឹងអំពី Colab (សំខាន់)

| រឿង | ការពិត |
|---|---|
| Session ជាប់បានយូរប៉ុណ្ណា? | បើនៅមានអន្តរកម្ម បានដល់ ~១២ ម៉ោង។ បើទុកចោល (idle) **~៩០ នាទី** វាដាច់ |
| បិទ tab វិញ? | session បិទ ហើយ URL ស្លាប់ — ការញែកភ្លេងឈប់ |
| URL ដដែលឬ? | **ថ្មីរាល់ពេលបើក tunnel ឡើងវិញ** — paste ថ្មីក្នុងកាត (១ ប្រអប់) |
| បើ session ដាច់ តើការងារបកប្រែឈប់ឬ? | មិនទេ។ ការងារនោះនៅតែបកប្រែបាន តែ **គ្មានការញែកភ្លេង** — សំឡេងដើមនៅជាប់ក្នុងភ្លេងផ្ទៃខាងក្រោយ ហើយត្រូវបន្ថយក្រោមសំឡេងខ្មែរ។ បើក Colab ឡើងវិញ រួចចាប់ផ្តើមម្ដងទៀតបានគុណភាពពេញ |
| ត្រូវការអ៊ីនធឺណិត? | ត្រូវ — Colab មិនដំណើរការក្រៅបណ្តាញទេ (បើអ្នកបិទវា គេហទំព័រភ្ជាប់មិនបាន) |
| សុវត្ថិភាព | URL + Key ដាក់តែក្នុងកាត Admin។ Email/Password របស់ Google **មិនចាំបាច់ផ្តល់** ទេ |

## ស្គ្រីបដែលនៅក្នុងថតនេះ

| ឯកសារ | តួនាទី |
|---|---|
| `colab-start.sh` | បញ្ជាតែមួយ៖ ដំឡើង Demucs → បើក API (GPU) → បើក tunnel → បង្ហាញ URL + Key |
| `demucs_colab.ipynb` | notebook ដែលរត់ស្គ្រីបខាងលើ រួចបង្ហាញ URL/Key/ស្ថានភាព API |

* API ដែល Colab រត់គឺ **ឯកសារដដែល** នឹងកំណែ Termux (`tools/demucs-termux/demucs_api.py`) —
  ដូច្នេះស្គ្រីបណាមួយដែលអ្នកមានរួចក៏ដើរដែរ ហើយគេហទំព័រមិនប្រកាន់ថាវារត់លើអ្វី។
* ចង់ប្តូរម៉ូឌែល (ឧ. `htdemucs_ft` សម្រាប់គុណភាពខ្ពស់ជាង តែយឺតជាង) ដាក់ `DEMUCS_MODEL=htdemucs_ft`
  មុនបញ្ជា `curl … | sh`។
* បើ Colab បង្ខំឲ្យប្រើ CPU (GPU មិនទាន់មាន) ស្គ្រីបនៅដើរបានដូចមុន — តែយឺតជាងទូរស័ព្ទបន្តិច។
